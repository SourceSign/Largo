**2. Purpose and target audience**

Largo is a practice tool for musicians who learn songs by ear – guitarists, bassists, pianists, singers and music students of all levels. Learning a song from a recording is hard because the music is too fast, difficult passages go by quickly, and the chords aren't written down anywhere.

Largo solves this: it plays any audio file the user owns at a slower (or faster) speed without changing the pitch, transposes it to another key, and repeats a selected passage in a seamless loop. It also analyzes the song on the device and shows the detected chords, key, tempo and bar numbers on a scrolling waveform, in time with the music. Settings are remembered per song, so users can continue practicing where they left off.

**3. Setting up and accessing the main features**

No account, login or setup is required. A demo song ("Largo Demo") is built into the app and opens automatically on first launch, so all features can be tried immediately. It can be reopened at any time: on iPhone, via "Open Demo Song" when no song is open; on iPad and Mac, via the "…" button in the bottom bar → "Open Demo Song".

Main features:
- Play/pause and skip back/forward 5 seconds with the buttons at the bottom.
- Speed: tap "1×" and choose a speed (e.g. 0.7). Swipe left in that popover (iPhone/iPad) for a fine-grained speed ruler. The pitch stays the same.
- Key: tap the key button (e.g. "G") and use − / + to transpose in semitones; swipe left (iPhone/iPad) for fine tuning in cents. The chord names change with the key.
- Loop: drag horizontally across the waveform to create a loop. Drag its edges to resize it, drag inside it to move it, and long-press it (right-click on Mac) for "Turn Loop Off" and "Clear Loop".
- Chords and bars: shown below and on the waveform while the song plays.
- Own songs: tap the folder button (iPhone/iPad) or press ⌘O (Mac) and choose any audio file (MP3, M4A, WAV, AIFF, FLAC, CAF) from Files, iCloud Drive or Finder.

No sample files beyond the built-in demo song are needed.

**4. External services, tools or platforms**

None. Largo does not use any external services, servers, data providers, authentication services, payment processors, analytics, advertising or AI services. All audio analysis (waveform, chord, key, tempo and beat detection) runs entirely on the device using Apple's own frameworks (AVFoundation and Accelerate). The app does not connect to the internet, has no user accounts and collects no data. There are no in-app purchases.

**5. Regional differences**

There are no regional differences. The app's features and content are identical in all regions. The user interface is in English.

**6. Regulated industry / protected third-party material**

Largo does not operate in a regulated industry and does not include any protected third-party material. The built-in demo song was created by the developer (all sounds are synthesized in code) and is royalty-free. Users open only audio files they already have on their own devices; Largo does not provide, stream or download any music. Copy-protected Apple Music tracks cannot be opened.
